    計算公式

    q_gross = Q/(B·L) + 基礎自重 + 額外加載；勾選扣除時 q_net = q_gross − σv(Df)。

    σ'v0 = σv − u，σv 由地表逐層累加（水位上 γt、水位下 γsat），u = γw·(d − GWT)。

    Δσ = q_net·B·L / [(B+z)(L+z)]，z 為中點至荷重作用面深度。

    沉陷

    σ'v0+Δσ ≤ σ'p：S = Cr·H/(1+e0)·log[(σ'v0+Δσ)/σ'v0]

    σ'v0+Δσ > σ'p：S = Cr·H/(1+e0)·log(σ'p/σ'v0) + Cc·H/(1+e0)·log[(σ'v0+Δσ)/σ'p]

    彈性層：S = Δσ·H/M。Δσ < 0 時以 Cr 計算回脹（負值）。

    使用限制

    等值筏基：只扣樁帽深度 Df 以上的開挖土重，Df～Dq 間土重已含於 σ'v0，不加也不扣；Dq 以上土層不計沉陷，樁身彈性縮短需另計。

    僅計最終主壓密與彈性沉陷，未含時間效應、次要壓密、鄰房疊加與抽水降壓。1 t = 9.81 kN。輸入只存在這台裝置的瀏覽器中。
