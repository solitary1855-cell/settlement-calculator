      只計影響深度以內的沉陷。相連的壓密層自動歸為同一黏土層群組，排水路徑 Hdr 依整個黏土層厚度決定（雙向 = H/2、單向 = H），Sc 只計影響深度以內的部分；cv 與排水條件以群組輸入。彈性層沉陷視為加載後立即發生。cv 換算：1 m²/時 = 8,760 m²/年，1 cm²/分 = 52.56 m²/年。Tv = cv·t / Hdr²；U ≤ 60%：Tv = (π/4)U²；U > 60%：Tv = 1.781 − 0.933·log(100 − U%)。假設初始超額孔隙水壓沿深度均勻分佈、荷重瞬時施加。

      計算公式

      q_gross = Q + 基礎自重 + 額外加載（皆為均布壓力）；勾選扣除時 q_net = q_gross − σv(Df)。

      σ'v0 = σv − u，σv 由地表逐層累加（水位上 γt、水位下 γsat），u = γw·(d − GWT)。

      Δσ = q_net·B·L / [(B+z)(L+z)]，z 為中點至荷重作用面深度。

      沉陷

      依規範式(4.4-1)、圖-解 4.4-3。各層先求 σ'0（中點有效覆土應力）、σ'c = σ'0 + 預壓應力（該層有填 σ'p 或 OCR 時優先）、σ'1 = σ'0 + Δσ，再判定壓密狀態：

      部份過壓密 σ'c > σ'0 且 σ'1 > σ'c：ΔH = H·Cs/(1+e0)·log(σ'c/σ'0) + H·Cc/(1+e0)·log(σ'1/σ'c)　(解 4.4-5)

      過壓密 σ'1 ≤ σ'c：ΔH = H·Cs/(1+e0)·log(σ'1/σ'0)　(解 4.4-6)

      正常壓密 σ'c = σ'0：ΔH = H·Cc/(1+e0)·log(σ'1/σ'0)　(解 4.4-7)

      壓密未完成 σ'c < σ'0：ΔH = H·Cc/(1+e0)·log(σ'1/σ'c)　(解 4.4-8)

      彈性層：S = Δσ·H/M。Δσ < 0 時以 Cs 計回脹（負值）。

      使用限制

      壓密時間依 Terzaghi 一維壓密理論（初始超額孔隙水壓均勻分佈、瞬時加載）。未含次要壓密、樁身彈性縮短、鄰房疊加與抽水降壓。1 t = 9.81 kN。
